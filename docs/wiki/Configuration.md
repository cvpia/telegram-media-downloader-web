# Configuration

首次进入 \`/dashboard\` 会打开配置向导。

1. **网络代理**：根据网络环境配置 HTTP 或 SOCKS 代理并测试连接。
2. **管理员密码**：创建后台管理密码。
3. **API 凭据**：填写 Telegram API ID 与 API Hash。
4. **Telegram 登录**：输入手机号、验证码；如启用两步验证，再输入密码。
5. **下载偏好**：选择媒体类型、目录结构、文件名模板和并发数。

## 敏感信息

以下内容不会以明文保存：

- API Hash
- Bot Token
- 代理密码

应用使用本地密钥加密敏感配置。密钥位于 \`data/.secret.key\`，必须与数据库一起备份。
