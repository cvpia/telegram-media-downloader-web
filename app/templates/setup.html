ONE-TIME SETUP

一次配置，直接开始下载

先确认网络代理，再完成管理员、Telegram 和下载设置。所有步骤都在浏览器中完成。

  1. 1网络代理
  2. 2管理员
  3. 3API 凭据
  4. 4Telegram 登录
  5. 5下载设置
01

设置网络代理

必须先通过网络测试。填写代理会测试代理连通性；不填写则可测试直连。代理凭据会加密保存。

支持 HTTP、HTTPS、SOCKS4 和 SOCKS5。示例：socks5://127.0.0.1:7890

02

设置管理密码

该密码用于保护 Web 管理台，至少 8 位。

03

连接 Telegram API

在 my.telegram.org/apps 创建应用后获取 API ID 和 API Hash。

04

登录 Telegram 账号

验证码会由 Telegram 官方发送。登录成功后，会话会保存在本机。

该账号启用了两步验证，请输入 Telegram 两步验证密码。

05

下载偏好

这些设置以后都可以在“系统设置”中修改。保存后前往频道管理添加下载来源。
